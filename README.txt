INVITATION NADA & HAMDI — SITE COMPLET

1. Ouvre ce dossier dans VS Code.
2. Clic droit sur index.html.
3. Choisis « Open with Live Server ».
4. Le site s'ouvre sur http://127.0.0.1:5500/.

IMPORTANT :
- 127.0.0.1 fonctionne uniquement sur ton ordinateur.
- Pour envoyer le site aux invités, publie le dossier sur Netlify Drop.
- Remplace le lien WhatsApp dans index.html : recherche https://wa.me/
  puis ajoute ton numéro sans + ni espaces.

- Le clic sur la fleur ouvre l'enveloppe et démarre la musique.
- Le site est responsive : téléphone, tablette et ordinateur.
